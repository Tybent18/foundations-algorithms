# C Programming Fundamentals

This repository contains a collection of C programs focused on core programming concepts and problem-solving techniques.

## Topics Covered
- Control flow and iteration
- Functions and recursion
- Arrays and pointer-based operations
- Mathematical computations (factorials, permutations, combinations)
- Statistical calculations (standard deviation)
- Bitwise operations and macros
- File I/O basics
- Algorithmic thinking in C

## Purpose
This repository documents my progression in low-level programming and systems-oriented thinking, with an emphasis on correctness, efficiency, and clarity.
