# Foundations & Algorithms

Small, readable programs exploring programming fundamentals, algorithmic reasoning, and cross-language debugging.

## What this repository demonstrates

- control flow, iteration, and functions
- arrays and pairwise operations
- basic debugging across Python, Java, and C
- introductory data-structure reasoning
- low-level problem decomposition in C

## Repository map

| File | Focus |
| --- | --- |
| [`pairwise.c`](pairwise.c) | Pairwise array operations and C fundamentals |
| [`debug.c`](debug.c) | Debugging practice in C |
| [`debug.java`](debug.java) | Debugging practice in Java |
| [`debug.py`](debug.py) | Debugging practice in Python |
| [`debug_datastruct.py`](debug_datastruct.py) | Debugging data-structure behavior |

## Run an example

C:

```bash
gcc -Wall -Wextra -pedantic pairwise.c -o pairwise
./pairwise
```

Python:

```bash
python debug.py
```

Java:

```bash
javac debug.java
java debug
```

## Purpose

This is a foundation repository: the emphasis is on making program behavior understandable before making it clever. It documents the early progression from syntax and control flow toward algorithms, data structures, and larger systems.
